# AI EHR 서비스 브랜드 네임 제안

> 대상: **AI 기반 전자건강기록(EHR, 환자·병원용) 서비스**의 브랜드/제품 네임
> 작성일: 2026-06-13
> 조건: 기존 헬스케어 관련 서비스에서 사용 중인 이름은 제외

---

## 1. 네이밍 방향 (콘셉트 축)

AI EHR(환자·병원용)는 **임상 신뢰**가 1순위, **AI 지능·자동화**가 차별점입니다.
세 축으로 후보를 설계했습니다.

| 축 | 메시지 | 톤 |
|---|---|---|
| A. 임상 신뢰·전문성 (병원 B2B) | "안전하게 기록하고, 정확하게 떠올린다" | 단단함, 의료 어원 |
| B. AI·연결·통합 | "흩어진 기록을 하나로, AI가 능동적으로" | 미래지향, 매끈함 |
| C. 한국적·공공 신뢰 | "환자–의료진–기록을 잇다" | 따뜻함, 직관성 |

---

## 2. 추천 후보 (웹 검색상 명확한 충돌 미발견 → 우선 검토)

### ⭐ 1순위: **Mediory (메디오리)**
- **구성**: Medi(의료) + Memory / -ory(history·directory 어감)
- **스토리**: 흩어진 진료기록을 환자의 **"건강 기억(health memory)"** 하나로 통합하고, AI가 필요한 순간에 정확히 떠올려준다. EHR의 본질(기록·회상)을 그대로 브랜드화.
- **강점**: 의미 직관 + 발음 쉬움 + 영문/한글 모두 자연스러움, B2B·B2C 확장 용이
- **검증**: 헬스케어 AI/EHR 영역에서 동명 브랜드 미확인

### ⭐ 2순위: **Anavi (아나비)**
- **구성**: Anamnesis(병력 청취·문진, 의료 정식 용어) + Vita(생명) / AI
- **스토리**: AI가 환자 **병력(anamnesis)** 을 능동적으로 떠올려 의료진의 판단을 돕는다. 임상 어원에 뿌리를 둬 전문성↑, 발음은 부드럽고 글로벌.
- **강점**: 의료진에게 설득력 있는 어원, 짧고(5자) 도메인 친화
- **검증**: 헬스케어 영역에서 동명 브랜드 미확인

## 3. 보조 후보 (콘셉트 우수 · 상표/도메인 클리어런스 필요)

| 이름 | 구성·의미 | 축 | 비고 |
|---|---|---|---|
| **Recordia (레코디아)** | Record + -ia, '기록의 세계' | B | 기록 그 자체를 브랜드화, 검색 청정도 점검 필요 |
| **Vireon (바이리온)** | Vita(생명) + -on, 생명력의 흐름 | B | 유사 브랜드(Vireo 계열) 충돌 여부 확인 |
| **Cleon (클레온)** | 의료 어원·간결한 음가 | A | 헬스 외 영역에 동명 존재(비충돌 가능), 점검 필요 |
| **이음 / Ieum Health** | 환자–의료진–기록을 '잇다' | C | 공공·신뢰 톤, '이음' 범용어라 식별력 보강 필요 |
| **온차트 / OnChart** | 온(溫·켜다) + Chart | C | 직관적이나 'Chart' 계열 다수, 차별화 표기 필요 |
